# Contributor instructions

This is a standalone public API repository. Keep all work within this repository.
Do not copy or link private implementation, configuration, credentials, logs,
signing material, or private Git history into it.

Read README.md and CONTRIBUTING.md before changes. Use Conventional Commits.
Run `mvn --batch-mode verify` and `python tools/verify_export.py` before publishing.
Report checks only when actually observed. Do not claim adoption, vulnerabilities,
advisories, certifications, or program approval without public evidence.
