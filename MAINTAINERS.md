Ritik P publishes this project under the name **Aqz** and the GitHub handle
**[@therealaqz](https://github.com/therealaqz)**.

The maintainer is responsible for reviewing API changes, preserving integration
compatibility, reviewing input-validation and trust-boundary concerns, triaging
private vulnerability reports, coordinating fixes and disclosure, and reviewing
the repository's build dependencies and publication contents.

Security maintenance covers the code and integration guidance published in this
repository. Third-party systems require their owners' explicit authorization.
Paper is an integration platform; this role does not confer maintainership of
Paper, Bukkit, or third-party plugins.

Use [GitHub issues](https://github.com/therealaqz/DeluxeGradient-API/issues) for
ordinary questions and bugs. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.
Public advisories should credit reporters with their consent and link the fix
and affected versions after coordinated disclosure.
